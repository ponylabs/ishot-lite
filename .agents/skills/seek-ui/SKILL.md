# 界面开发与审查

本 Skill 拥有设计和审查流程、视觉基础、几何与交互判断；对齐、间距、图标细节在按需参考中。响应式行为使用独立的 [响应式 UI](../seek-responsive-ui/SKILL.md)。不把此处的设计专项再拆成更多 Skill。

## 按影响选择检查

普通开发不等于全面设计审计，但小变更也不能省略实际页面检查。

| 变更 | 必须检查 | 额外记录 |
| --- | --- | --- |
| 局部文字、复用图标、颜色或间距 | 实际页面中改动对象、直接受影响邻居及相关状态；运行适用测试 | 简短说明结果和缺口，不默认要求单独计划、轴线图或截图报告 |
| 页面布局、共享组件或全局样式 | 追踪消费者，检查组装后页面中不同布局、内容和状态；只对有依据的等价场景复用证据 | 说明范围；用户要求或回归风险需要时保留真实起始版本与可比截图 |
| 明确的全面审查 | 覆盖约定区域和相关状态，区分已检查结果、缺陷与未检查范围 | 按任务要求保存覆盖和证据；要求前后对比不自动等于全产品审计 |

### 最低检查

打开实际页面，在上下文中检查对象，不只看 CSS 或孤立组件。

- 颜色或透明度：检查项目支持的明暗主题、受影响的前景/背景组合及状态。
- 布局、间距、排版或尺寸：检查受限容器、长文字和换行；检查改变的断点两侧、对齐、裁切及操作可达性。
- 交互：执行改变的路径，检查受影响的焦点、禁用、加载、失败、展开和遮挡状态；不是遍历所有无关组合。
- 共享组件或全局样式：追踪消费者，检查不同的组装布局与状态，单个孤立示例不证明完整覆盖。

必要场景不可用时说明未检查项、原因和补验方法。明确标注的生产组件 fixture 只能提供部分证据，不是实际页面通过。源码和自动测试不能单独证明实际渲染正确。文档改动或有证据证明渲染未变的重构，不要求新增截图，需说明依据。

批量处理相关修改，复用当前应用和未失效证据。交付、审查或推送前只补查累积交互、遗漏和失效证据，不在每个阶段重复全部验证。前后对比使用真实起始实现，包括未提交工作；禁止重造“修改前”图冒充原图。

## 选择规则拥有者

布局读 [对齐](references/alignment.md) 和 [间距](references/spacing.md)；选择、绘制、复用或审查图标及图标控件时读 [图标](references/icons.md)。其他任务只读相关部分，不默认全量加载。

Web 项目按 [文档约定](../../../docs/AGENTS.md) 使用实际项目的 `docs/web-styling.md`；需要独立圆角规范时使用 `docs/ui-radius.md`。参数值归实际主题和组件实现，文档拥有语义、映射与例外。没有这些场景时不建空文件，不照搬其他产品的字号、字体、圆角、颜色、固定最小宽度和审批名单。

## 先复用再新增

先检查已有组件、容器、扩展点和交互。能力适合现有组件就扩展，不为局部功能再建平行容器。共享组件的状态与生命周期遵循所在模块契约；局部问题先修消费者布局，不改共享资源使其他调用者退化。

## 视觉基础与几何

沿用目标页面或最接近的成熟同类页面的主题、排版层次和完整视觉处理，不为单个元素随意创建新值。同级元素保持尺寸关系，颜色在相关主题中可读。

先确定组件角色与尺寸档，再比较容器关系。高度、圆角、曲线、内缩和材质共同决定协调性；圆角数值相同不等于协调，文字换行也不必然需要更大圆角。

- 内嵌轮廓：协调内外曲线和间距。半径相减仅对同心圆弧精确；超椭圆还要看斜角空白。
- 贴边或相邻：外容器拥有外露角，内部接缝保持合理；悬停层和伪元素服从轮廓，同时不能裁掉菜单和焦点。
- 独立子卡片：采用自身角色/尺寸，而不是无条件继承外层弹窗圆角。
- 圆或胶囊：保留形状，包括头像容器和图片，按项目主题约定处理。

检查悬停、按下、选中、加载和禁用状态下填充、描边和覆盖层是否稳定；不要重复叠加中性边缘。静态规则只能排除非法声明，实际渲染比较才判断效果。只应用于任务范围，不顺便全站重做样式。

## 交互与反馈

按 [错误处理](../seek-error-handling/SKILL.md) 判断失败保证，再选择反馈存续时间：

- 短暂反馈的状态和渲染由能跨源面板关闭存活的拥有者负责，避免删除后源面板消失导致反馈丢失。
- 操作失败保留仍有效的数据，删除失败保留对象；内容已有数据时在附近提供简短错误与重试，不换成空白页。
- 字段错误归字段；初始加载完全失败时提供明确空状态与恢复入口。错误短且可行动，不泄露内部细节。
- 使用项目一致的加载处理，避免互相竞争的指示器；没有信息价值时不追加加载文字。

视图销毁时解除短期订阅，跨视图操作状态留在适当拥有者；旧异步响应不能覆盖新对象。菜单、浮层和 tooltip 应可通过外部点击退出，可聚焦者支持 Escape；放置在视口内，避开祖先裁切和覆盖。只向有空间的方向翻转，两侧都不够时不能来回震荡。滚动条不遮挡内容。

遵循支持平台的标题栏、安全区及窗口约定。检查总偏移，局部修复不改全局安全区变量。

## 组合检查和维护

先看整体组合，再看组内、跨组关系、远处同级和展开内容。对齐检查两端，保留菜单、焦点、错误提示、窄屏操作和草稿。局部截图和 fixture 只证明其实际展示的范围。

每条规则只保留一个拥有者，主入口引用而非复制。调整规则时说明适用条件、选择、例外和可观察验证，更新区分性案例并移除替代的旧说法。区分迁移范围和未来修改范围，不暗示未检查页面已符合新规则。只自动化可机械判断的约束。

项目已有设计/产品审查要求时遵循原触发条件，不凭空指定审批人。需要录制演示时使用 [seek-record-browser-gif](../seek-record-browser-gif/SKILL.md)。
