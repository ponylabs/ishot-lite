# 图标与图标控件

在 [界面检查流程](../SKILL.md) 的实际页面或弹窗中应用。

## 先复用

搜索已有图标库和同类 UI 的语义与变体，复用共享组件，不在功能中复制 SVG。大小、颜色、位置不匹配通常属于变体或消费布局，不是画一个近似图标的理由。

只有已有图标不能表达含义，或用户要求独特设计时才新画。先说明最接近方案和未满足的含义；遵守项目已有设计审批，不凭空增加审批人。不要为修一个消费者而重画共享图形。

## 风格与可辨识性

沿用项目的图标系统，比较轮廓、线端、转角、粗细、留白和复杂度。图标的语义方向、选中标记、状态点、镂空及品牌配色应保留，不因统一外观全部归一为工具栏线框。

结构与留白要平衡，不强制对称；避免意外倾斜、头重脚轻、相切黑结或实际尺寸下消失的空隙。适当利用重叠、嵌套和遮挡处断线说明含义，不强制每个图形闭合。

## 尺寸与渲染

按所属控件支持的尺寸、字重、颜色和标签比较，用圆形、矩形控件和同级图标作参照。开放轮廓可能比密集实心图形需要更多外延；不能按墨水面积统一或填满每个 viewBox。

共享 viewBox 改动影响每个消费者的实际 CSS 尺寸，要同时检查紧凑菜单与较大图标按钮。必要时调整消费者支持的图标尺寸，同时保留按钮背景和点击区域。

模糊时依次检查 CSS 尺寸、祖先 transform、viewBox、绘制边界、描边/填充方式、设备像素落点和颜色透明度。非 16 的 viewBox 并非错误。不能在普通复用修复中擅自切换 non-scaling-stroke 或把填充轮廓改成描边；渲染契约变化需要独立范围与消费者验证。

直线清晰度取决于最终 DPR 下的中心和宽度，整数源坐标不保证清晰。只在布局造成意外亚像素定位时按设备像素调整覆盖层，保留锚定和视口限制。不全局取整曲线或用 crispEdges 掩盖错误；曲线/斜线抗锯齿和某些非整数线宽的部分覆盖是正常现象。

## 新图标及用户素材

确定含义、位置、实际尺寸、同级和状态，只有缺失信息改变设计时才提问。输出可编辑 SVG，按项目支持的字重变体保持共同结构；在实际控件和主题中校准轮廓、间隙、中心与重量，不依赖消费者特例缩放。

规范化用户素材前保留原图与可识别特征。可以展示已有等价图标，但不能擅自替换用户要求处理的形状。区分画布、尺寸、描边和颜色继承等技术修复与轮廓/隐喻变化，解释必要简化。栅格参考不照抄压缩锯齿；无法恢复的关键特征要明确。

交付原始/调整/同级的同条件实际尺寸比较，说明语义选择和未决项。草案与已批准图标区分；实施时注册可复用组件和文档。

## 使用关系与交互

区分点击目标、按钮底、图标 slot 和实际轮廓。相同 SVG 尺寸或点击范围不保证相同视觉重量，先修容器和意外 CSS 覆盖。

属于同一操作、值或输入提示的图标与文字遵循同一前景角色、有效透明度和状态变化；状态、警告、品牌和独立清除动作可以不同。检查祖先透明度和主题组合，不以新规范声明未检查页面已合规。

图标动作应有可访问名称和焦点。模糊图标动作使用项目共享 tooltip，有实质说明的内容使用适合阅读的共享提示组件，不随手用 title 取代完整交互。移动端和标签折叠见 [响应式 UI](../../seek-responsive-ui/SKILL.md)。位置归 [对齐](alignment.md)，距离归 [间距](spacing.md)。

## 验证

普通复用或摆放检查受影响控件的实际尺寸和相关状态，不要求固定截图数量。新图形、描边或渲染变化应比较相关尺寸、字重及同级；像素/描边缩放有变化时检查 DPR 1 与 2，颜色或视觉重量有变化时检查明暗主题。

放大图用于诊断像素，不能代替实际尺寸下识别、裁切、中心、间隙与相邻文字的判断。全套变更追踪受影响图标族、消费者和字重，包括源码未改但渲染受影响的图标。明确要求全套审查时才逐个盘点；无关重复图标记录为建议，不扩张本次任务。
