# 间距与分组

应用于 [界面检查流程](../SKILL.md)。距离应解释文字、输入和操作属于哪个对象或动作。

先按对象、动作或重复单元分组，不按 DOM 兄弟、背景或组件名分组。每个嵌套层级独立判断；外层间距变大不代表内层必须同步变大。例如 checkbox 与文字是一项，选项组成字段，字段组成模型，模型组成列表。

没有分隔线时，可比较组之间的距离应明显大于组内距离；仅相等只是没有颠倒的最低边界，未必能形成分组。重复组合保持相同 gap、padding 和对齐，标签变长不能成为不一致间距的理由。

换行、元数据、子组或独立操作增加复杂度时，适当增加外围间距以保持归属；不能按卡片面积推导 gap，也不能乘大所有 margin。分隔线和不同背景能增强分组，但标题仍应更靠近自己的内容而非前一组。

按实际尺寸观察完整空白，包括 padding、行高、字形留白和边框。16px/8px 等 CSS 比例本身不证明分组正确，解释标签必须有明确归属。比较两段间距时明确各自两端，保持端点选取一致；相同可见间距可能需要不同 margin。

复用页面与主题的间距约定，保持 [对齐](alignment.md) 轴线；本参考不另建数值尺度。
