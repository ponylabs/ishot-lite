# 对齐

应用于 [界面检查流程](../SKILL.md)，同类元素包括可选图标与操作的占位。

## 先结构，再视觉微调

区分点击目标、按钮可见背景、完整图标盒与绘制轮廓。图标的有意留白属于布局盒，不因像素未碰参考线就裁掉；扩大点击区域不能移动图标盒。先检查容器、slot、列、间距和 CSS 覆盖，再做光学校正。

如果失衡跟随同一图标出现在各处，修共享图标；只有某组合需要调整时，给出局部理由并比较同级。DOM 嵌套不自动决定视觉缩进。透明点击 padding 不等于可见边缘。

行内 SVG 的 vertical-align: middle 根据字体基线和 x-height，不保证与可见文字中心一致；检查中英文、等宽字体、行高和换行。不能为了居中图标就禁止多行链接换行。

## 同时明确对象和轴线

| 关系 | 判断对象 | 常见问题 |
| --- | --- | --- |
| 左边缘 | 同角色文字在组内与跨组有一致起点 | 每个组件的 inset 单独合理，整体却错位 |
| 水平居中 | 图标加标签或整个空状态组合在指定容器内居中 | 只居中文字，再把图标挂在外侧 |
| 垂直居中 | 单行图标/文字或同级工具栏的可见中心平衡 | 相同 CSS 高度掩盖 SVG 留白和行盒差异 |
| 基线/首行 | 混合字号的基线，多行文字前图标对应首行 | 图标对整个多行段落居中 |
| 两端 | 标题靠阅读边缘、操作靠尾部边缘 | 将所有图标均分到整个宽度 |
| 重复列 | 各行时间、操作、文件的对应 slot | 只有最后图标对齐，其他列漂移 |

菜单与触发器、搜索框与结果行比较完整文字 inset：外 padding、border、前导 slot 和 gap。图标尺寸不同仍可保持相同文字起点。相邻统计先比较字体、大小、字重和行高，不先移动图标。

按钮在自身容器居中，欢迎组合在主区域居中，空状态在标题/过滤器以下剩余内容区居中；固定 top margin 不是居中。短窗口容纳不下时，保留紧凑顶部布局和滚动访问。

先统一同级控件尺寸和 slot，再做有依据的小光学校正。保持点击区域可用且互不重叠，不用 transform 掩盖父层布局问题。检查 [间距](spacing.md) 时不改变选定轴线。
