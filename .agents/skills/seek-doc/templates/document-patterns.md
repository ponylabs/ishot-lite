# 可选文档骨架

这是选择结构的参考，不是待批量实例化的模板。依据读者任务选择必要内容，复用现有页面；没有事实的章节应省略，不留“待补充”占位海洋。现有格式由解析器或项目规范拥有时遵从它。

## 操作指南

- 目标与适用范围：完成什么，什么情况下不要使用。
- 前提：环境、权限、版本、数据和已完成的步骤。
- 最短安全步骤：精确命令/输入，按依赖顺序排列。
- 验证结果：读者应看到的结果及如何检查真实状态。
- 失败与恢复：主要失败、部分执行结果、恢复或回退边界。
- 深入阅读：复杂原理和精确参考的拥有者链接。

验收：从给定前提出发实际执行安全范围内的路径，不能省略隐含工作目录或把模拟结果写成真实操作。

## 模块参考 / README

- 能力与选择：对使用方提供什么，何时适用。
- 公开入口：如何导入、调用、配置或启动；按真实形态写，不给库虚构服务启动步骤。
- 行为契约：输入输出、状态和资源责任、错误、取消、时序及兼容性中实际重要的内容。
- 限制与扩展：使用或维护会遇到的真实限制，不是普通清理待办。
- 实现导航：组件关系和设计要点，链接源码及架构理由，不复制完整字段/API 清单。

验收：核对清单与入口，执行最小示例，检查真实调用方和关键失败路径。

## 架构说明 / 决策记录

架构说明描述当前模块、责任、状态和数据流、扩展约束及入口；决策记录描述当时背景、真正可行的替代、选择依据、后果和验证。两者可以相互链接，不能把尚未接受的提案写成当前架构。

验收：设计与实现有冲突时报告差异；历史证据保持时间和版本边界。

## 局部 AGENTS / 导航页

局部 AGENTS 只写该范围独有、会改变开发决策的约束，链接通用 Skill 和事实来源；导航页说明直接下级各自解决什么问题，不复述正文。没有独立规则或导航价值时不新增。

验收：Agent 从根入口沿目标路径能找到适用规则；不能通过多个副本维护同一规则。
