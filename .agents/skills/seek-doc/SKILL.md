# 维护项目知识

让读者能找到正确入口、安全完成任务，并让维护者知道事实由谁负责。本 Skill 管文档分类、归属、生命周期与交付；[seek-prose](../seek-prose/SKILL.md) 管句段语义和表达判断。先服从适用的 AGENTS、已确认契约和实际门禁，不用模板覆盖机器格式或用户约束。

## 固定文档契约

先读取 [docs/AGENTS.md](../../../docs/AGENTS.md)，按其固定名称、职责及条件创建；本 Skill 只维护操作方法。修改业务后原位更新项目事实，不能持续保留初始化问卷。现有拥有者不足才新建，完成后收敛重复、失效与过程内容。

## 输入与范围

确认目标文件、模块或本次差异，以及任务是审查还是修改。范围缺失时请求最小必要范围，不默认全仓整理。只读审查仅输出发现；写作、移动、删除及发布分别遵循已有授权。默认排除第三方源码、生成文件和冻结历史；准确理解历史引用时可以只读对应记录，不能顺手现代化它。

## 执行主线

1. 读取根及目标路径 AGENTS、目标文档、对应实现与测试、导航或生成入口。核对当前分支和任务基线，不凭旧对话认定事实；需要远端比较时先安全获取当前引用，离线则报告基线限制。
2. 为每页确认一个主要读者任务：操作、学习、查契约、理解架构、理解决策或给 Agent 约束。按 [类型与归属](references/document-types.md) 找最近的事实拥有者，不根据目录名猜模块形态。
3. 写下读者起点、预期可观察结果、主要失败和恢复路径，再选择需要的 [可选骨架](templates/document-patterns.md)。小文件、生成格式和机器解析格式保留其约束，不强套摘要、目录或元数据。
4. 先修改事实拥有者，再修改引用和派生物。原位修订当前说明，删除失效文字；新建文档必须说明服务谁、现有文档为何不合适、什么变更会触发更新。
5. 对命令、配置、默认值、错误与平台声明执行 [事实核验](references/fact-checking.md)。来源阅读不等于实际运行通过；涉及破坏性或外部操作时先守住授权和安全边界。
6. 新增、移动、拆分、删除、翻译或生成文档时使用 [生命周期与派生内容](references/lifecycle.md)，同次维护所有已识别消费方和引用，不能只移动文件。涉及持久化或跨版本契约的格式、默认行为或错误策略改变时，即使结构字段没变，也读取其中的兼容证据说明并核对已有读写方；行为变化本身不要求新建持久化类型变更记录。
7. 用 [seek-prose](../seek-prose/SKILL.md) 检查完整含义、冗余与措辞行为。普通文档写当前现实，提案和历史明确标识；不把临时调查、进度或废弃方案堆进 README。
8. 依据 [审查与验证](references/review.md) 先跑针对性检查，再运行项目实际的文档、生成、构建和业务检查。最终差异分别审事实与表达；操作声明改变时重新验证精确示例。

## 失败与退出

- 事实与实现冲突：指出冲突和证据，不能为通过检查改掉业务要求，也不能改测试迁就未证实的文案。
- 缺密钥、网络或平台：标明哪项声明未验证、已有证据、剩余验证责任与所需条件，不把单平台结果扩大为全平台通过。
- 内容或预算检查失败：先调整归属与结构、再消除冗余；必要内容确实需要更多空间时说明理由，不擅自抬高门禁或删掉承诺。
- 新增门禁：有效样本应通过，无效样本应在真实检查入口失败；只运行辅助函数不能证明 CI 能拦截。
- 完成时报告范围、事实归属变化、引用/生成影响、实际命令及结果、未验证项和剩余责任。允许“无需文档修改”；审查结果不伪装为已修复。

## 按需读取

- [类型与归属](references/document-types.md)：文档分类、分层阅读、检索元数据和目录准入。
- [事实核验](references/fact-checking.md)：精确操作、证据范围、失败和不可执行分支。
- [生命周期与派生内容](references/lifecycle.md)：迁移、归档、双语、站点与生成物，仅在项目涉及时应用。
- [审查与验证](references/review.md)：读者验收、规模控制、检查选择和负例。
- [页面表达与导航](references/page-style.md)：读者深度、清晰措辞、折叠与渲染安全。
- [可选骨架](templates/document-patterns.md)：按职责选取，不能整批生成空文档。
- [来源与迁移覆盖](references/upstream-map.md)：本 Skill 的上游基线和适配理由，仅维护模板或审计迁移时读取。

## 专项工作

对外破坏性变化使用 [升级指南](../seek-create-upgrade-guide/SKILL.md)。普通文档改动按项目已有语言政策最小同步；扩展翻译流程只能由用户按名称调用，不能从本 Skill 自动加载。
