# Agent 使用体验

- **从最少上下文开始**：先展示目的、可用动作和约束，细节在需要时加载。
- **显式提供发现入口**：每份延迟加载资料都需要清楚的描述和可靠的获取方式。
- **关键约束提前可见**：权限、破坏性影响和必要验证必须出现在相关动作之前。
- **输出有界**：返回简洁结果及可获取细节的标识或路径，不倾倒整份日志或文档。
- **利用局部上下文**：结果附带有限且可能需要的相邻内容，例如回复前的几条消息。明确截断和遗漏，并给出继续读取方法。
- **衡量总工作量**：节省上下文不能换来更多搜索、重复读取和错误。

## 工具定义

- 删除调用结果本身就能说明的显然约束，不重复解释不存在文件读取失败等常识。
- 描述行为和返回内容，不描述内部实现、结果里已经可见的标记或执行机制。
- 参数默认值、范围、配对和设置时机写在该参数描述或 schema；随配置变化的描述通常应归参数。
- 每个事实只写一次，不在系统提示、工具总描述、参数及其他工具之间复制。
- 工具定义变更前后比较首轮提示 token 数；同时核对发现、理解与完成任务是否需要更多工作。无可用计量时说明未测，不编造数字。

本 Skill 设计信息与工作流，不统管文档、规则或 Skill 的自动晋升；相关内容仍由各自拥有者维护。
